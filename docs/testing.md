# 验证说明（v0.1.0）

本文记录 v0.1.0 在作者环境中的验证情况。

## 验证环境

- 操作系统：Windows 11
- 浏览器：Chrome，视口 1280×720
- 日期：2026-11-12

## 验证范围

| 类别 | 内容 |
| --- | --- |
| 自动行为检查 | 25 项，覆盖移动、跳跃、冲刺、攻击判定、受击无敌、守卫预警、危险区重置、死亡重开、开门、胜利、暂停、静音和音频数值 |
| 自动通关 | 脚本向浏览器发送键盘事件，从起点打到通关界面，不改写游戏内部数据 |
| 人工试玩 | 作者试玩 |
| 启动方式 | 在 Windows 11 上运行 `scripts\play.cmd` |

自动检查脚本由生成游戏的模型在同一次运行中编写并执行。

## 验证结果

- 自动行为检查：25 项全部通过，浏览器控制台无错误。项目文件整理后对同一份 `game/index.html` 复查一次，结果相同。
- 自动通关：完成。
- 人工试玩：作者反馈基本功能可以正常使用。
- 启动方式：本地服务在 127.0.0.1 上启动，系统默认浏览器（Microsoft Edge）自动打开了游戏页面。

## 验证限制

- **自动通关依赖内部状态。** 通关脚本通过游戏的调试接口读取坐标、守卫状态和计时来决定按键时机，不依据画面判断。它验证的是游戏逻辑可以走通，不反映玩家的实际操作体验。
- **未经独立复核。** 自动检查由模型编写和执行，没有第三方复核。
- **人工试玩范围有限。** 反馈只确认了基本功能可用，未对手感、难度和听感作出评价。
- **音效未经试听确认。** 音效只做过离线渲染的数值检查（无 NaN、无削波、非静音）。
- **性能未测。** 没有测量帧率。
- **跨浏览器验证未完成。** 行为检查只在 Chrome 中进行；在 Edge 中只确认了页面可以打开，未做行为检查或试玩；其他浏览器未测试。
- **其他未测项。** 直接以文件方式打开 `game/index.html` 未测试；切换窗口时的自动暂停只用合成事件验证过。
