# 测试摘要（v0.1.0）

这是一份摘要。下面的"25 项通过"是作者环境中的测试记录，不是读者可以独立核对的结果：公开包不包含对应的完整检查脚本和原始测试数据，读者不能直接重跑这些检查。读者能自己验证的，是按 README 的步骤运行游戏并试玩。

## 做过的

- **自动行为检查**：生成游戏的模型在同一次运行中自己编写了检查脚本。最终一轮 25 项全部通过，浏览器控制台 0 条错误。覆盖移动、跳跃、冲刺、攻击判定、受击无敌、守卫预警、危险区重置、死亡重开、开门、胜利、暂停、静音和音频数值。
- **自动通关**：脚本向浏览器发送键盘事件，从起点打到通关界面，没有改写游戏内部数据。
- **复查**：整理项目文件之后，对同一份 `game/index.html` 重跑了同一套检查，25 项通过。执行者是 Claude Code，无人手操作。
- **人工试玩**：项目所有者试玩后表示基本功能可以正常使用。

测试环境：Windows 11，Chrome，视口 1280×720。

## 边界

- 自动通关脚本通过游戏的调试接口读取内部状态（坐标、守卫所处状态和计时等）来决定何时按键。它不看画面，**不是纯视觉通关**。它证明的是逻辑走得通，不代表人类玩家的体验。
- 自动检查由模型编写并执行，没有经过独立的第三方复核。
- 人工反馈很简短，没有逐项说明试了什么，不是全面验收。手感、难度、听感都没有具体评价。
- 音效只做过离线渲染的数值检查（无 NaN、无削波、非静音），没有经人耳试听确认的记录。
- 没有测量帧率；行为检查只在 Chrome 中做过；没有测试直接打开文件的方式；切换窗口时的自动暂停只用合成事件验证过。
